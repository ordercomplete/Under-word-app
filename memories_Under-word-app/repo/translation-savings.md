# Збереження обраних перекладів при перемиканні заповітів

## Проблема
При зміні книги з Старого Заповіту (OldT) на Новий Заповіт (NewT) або навпаки, обрані версії перекладів скидалися на дефолтні.

## Рішення
Створено загальний стан `testamentVersions`, який зберігає обрані версії окремо для кожного заповіту:
- `OldT`: ["LXX", "UTT"] (дефолт)
- `NewT`: ["TR", "UTT"] (дефолт)

## Зміни

### 1. PassagePage.js
- Додано стан `testamentVersions` для зберігання версій окремо для OldT та NewT
- Створено константу `DEFAULT_VERSIONS` для дефолтних версій
- Оновлено функції `handlePrevChapter` та `handleNextChapter` для:
  - Збереження поточних версій перед перемиканням розділів
  - Перевірки зміни заповіту при переході між книгами
  - Встановлення збережених версій для нового заповіту при зміні
- Оновлено функцію `handleSelectBookAndChapter` (через PassageOptionsGroup) для:
  - Збереження поточних версій перед перемиканням книг
  - Встановлення збережених версій при зміні заповіту

### 2. PassageOptionsGroup.js
- Оновлено пропси для отримання `testamentVersions` та `setTestamentVersions` з батьківського компонента
- Видалено локальний стан `testamentVersions`
- Оновлено функцію `handleSelectBookAndChapter` для використання пропсів
- Створено константу `DEFAULT_VERSIONS` для дефолтних версій

## Логіка роботи

### При зміні книги через BookSelector:
1. Зберігаємо поточні версії для поточного заповіту
2. Визначаємо новий заповіт
3. Якщо заповіт змінився, встановлюємо збережені версії для нового заповіту
4. Якщо немає збережених версій, використовуємо дефолтні

### При перемиканні розділів (Prev/Next):
1. Зберігаємо поточні версії перед перемиканням
2. Перевіряємо, чи змінився заповіт при переході до наступної/попередньої книги
3. Якщо заповіт змінився, встановлюємо збережені версії для нового заповіту

### При свайпі (мобільний режим):
Та сама логіка, що й при перемиканні розділів

## Приклади використання

### Збереження версій:
```javascript
// Користувач обирає LXX + UTT для OldT
testamentVersions.OldT = ["LXX", "UTT"];

// Користувач обирає TR + KJV для NewT
testamentVersions.NewT = ["TR", "KJV"];
```

### Отримання збережених версій:
```javascript
const savedVersions = testamentVersions[newTestament] || [];
const versionsToSet = savedVersions.length > 0 
  ? savedVersions 
  : DEFAULT_VERSIONS[newTestament];
```

## Переваги
- Зберігаються обрані версії при перемиканні між заповітами
- Відсутнє дублювання коду (використовується константа DEFAULT_VERSIONS)
- Легко розширити для додаткових заповітів (якщо потрібно)

## Можливі покращення
- Зберігання версій у localStorage для збереження після перезавантаження
- Додаткова індикація того, що використовуються збережені версії
- Можливість скидання до дефолтних версій для конкретного заповіту
