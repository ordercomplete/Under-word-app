---
name: safe-edit
description: Безпечне редагування файлів для слабших локальних моделей
---

Перед будь-яким редагуванням файлу:
1. Обов'язково прочитай його повністю (або релевантну частину).
2. Зроби мінімальну можливу зміну.
3. Після зміни (якщо це JSON) — перевір валідність.
4. Не чіпай інші частини файлу.
