## 🎯 Ключові функціональні модули

### 1. PassagePage - Мультивіконний перегляд Біблії

**Особливості:**

- **До 4 незалежних панелей** (десктоп) або 2 (мобільний, < 992px)
- Кожна панель має власний стан: `ref` (книга.розділ) + `versions` (версії)
- Lazy loading через `React.lazy()` та `Suspense`
- Кешування глав в `sessionStorage` (1 година) та `chapterCache`
- Автоматичне відновлення стану при перезавантаженні сторінки

**Навігація:**

- Кнопки Prev/Next між главами
- Свайпи на мобільних (60px поріг)
- Автоматична корекція версій при переході між Старим/Новим Заповітом

**Додавання панелей:**

- Кнопка "+" для створення нової панелі
- Нова панель копіює стан першої панелі
- Обмеження кількості панелей для адаптивності

### 2. InterlinearVerse - Інтерліннеарний перегляд вірша

**Функціонал:**

- Вирівнювання слів оригіналу та перекладу за Strong кодами (G/H)
- Binary search для оптимізації великих масивів віршів
- Floating tooltip з інформацією при наведенні на слово
- Підтис вірша тільки при першому відкритті глави
- Підтримка єврейської RTL розкладки (THOT)

**Дані слів:**

- `strong` - код Strong (G або H + номер)
- `lemma` - лема слова
- `morph` - морфологія
- `dict` - код словника перекладу (опціонально)

### 3. LexiconWindow - Словниковий пошук

**Джерела даних:**

1. Спочатку шукає словник перекладу (за `dictCode`)
2. Якщо не знайдено - завантажує Strong's словник

**Інформація вікна:**

- Слово (оригінал)
- Транслітерація
- Переклад
- Морфологія
- Значення (meanings)
- Визначення (definitions)
- LXX Usage (використання в Септуагінті)
- LSJ визначення (грецька лексика)
- Єврейські еквіваленти

**Навігація по історії:**

- Back/Forward кнопки в заголовку
- Свайпи між словами (на мобільних, 50px поріг)
- Глобальна історія з розділенням на Strong's та Translation

**Таби:**

- Словник (основна інформація)
- Значення (meanings)
- Визначення (definitions)
- LXX Usage
- LSJ
- Граматика (morphology/grammar)

### 4. PassageOptionsGroup - Панель управління панеллю

**Елементи:**

- Кнопка вибору версій (TranslationSelector)
- Вибір книги (BookSelector)
- Вибір розділу (ChapterSelector)
- Кнопки навігації (Prev/Next)
- Кнопка додавання панелі (+)
- Кнопка закриття панелі (×)
- Іконка шерингу

## ⚙️ Технічні особливості

### Оптимізація продуктивності:

- **AbortController** для скасування запитів при швидкій навігації
- **Debounce** збереження стану (500ms затримки)
- **sessionStorage кеш** для core.json (термін дії 1 година)
- **chapterCache** - кешування глав
- **Binary search** для великих масивів віршів
- **Фільтрація дублікатів** в історії слів

### Адаптивність:

- `react-responsive` для визначення ширини екрана
- Автоматична адаптація кількості панелей (< 992px та < 520px)
- Підтримка safe-area для мобільних пристроїв
- Відновлення 1 vs 2 віконних режимів на мобільних

### Service Worker:

- Офлайн-режим
- Preload критичних ресурсів (core.json, lang.json, translations.json)
- Автоматична перевірка оновлень кожні 60 хвилин
